# Imagery assets

- `black-marble-8k.jpg` / `black-marble-4k.jpg` — NASA Earth Observatory [Black Marble 2016](https://science.nasa.gov/earth/earth-observatory/earth-at-night/maps/) (Suomi NPP / VIIRS), resized and JPEG-compressed from the public 3 km global map. US government work, public domain.
- `earth-dark.jpg` — a small solid dark texture generated for the Dark basemap (not NASA imagery).
